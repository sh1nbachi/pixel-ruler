# Пиксельная линейка (Pixel Ruler)

Десктопная утилита на Python (Tkinter + Pillow) для измерения расстояний в пикселях
прямо на фотографии или скриншоте. Ставишь точки — программа соединяет их в ломаную,
считает длину каждого отрезка и итог, а результат можно сохранить отдельным файлом
с разметкой, наложенной поверх оригинала в полном разрешении.

Интерфейс двуязычный (RU / EN), выбранный язык запоминается между запусками.
Программа работает полностью офлайн: изображения и настройки никуда не отправляются.

## Возможности
- Открытие фото и скриншотов: PNG / JPG / JPEG / BMP / GIF / TIFF / WebP.
- Постановка точек левой кнопкой, удаление последней — правой.
- Авто‑соединение точек в последовательность 1→2→3→… с длиной каждого отрезка.
- Приближение колесом мыши (зум к курсору) и перемещение перетаскиванием.
- Опция «Замкнуть контур» — соединяет последнюю точку с первой (периметр).
- Панель замеров справа: координаты точек, длины, итог в пикселях.
- **Экспорт изображения с разметкой** — сохраняет копию фото в исходном разрешении
  с наложенными линиями, точками и подписями длин (для отчётов и переписки).
- **Чёткость на HiDPI** — приложение DPI‑aware: окно, нативные диалоги и текст
  рисуются в физических пикселях монитора, без «мыла» от масштабирования Windows;
  на 100% зуме один пиксель фото попадает ровно в один пиксель экрана.
- **Адаптивный ресэмплинг** — при уменьшении используется LANCZOS (резкая картинка),
  при увеличении NEAREST (жёсткая сетка пикселей, удобно попадать точкой в пиксель).
- **Двуязычный интерфейс (RU / EN)** с переключателем в тулбаре; язык запоминается
  в профиле пользователя и при первом запуске определяется автоматически по системе.
  Локализованы также диалог открытия/сохранения и всплывающие ошибки.

## Управление
| Действие | Как |
|---|---|
| Поставить точку | Левый клик |
| Двигать фото | Зажать ЛКМ и тянуть |
| Удалить последнюю точку | Правый клик |
| Приблизить / отдалить | Колесо мыши |
| Открыть другое фото | Кнопка «Открыть изображение» |
| Сохранить с разметкой | Кнопка «Сохранить с разметкой» |
| Замкнуть контур | Галочка «Замкнуть контур» |
| Сменить язык | Выпадашка «Язык» в тулбаре |

## Установка и запуск из исходников
Нужен Python 3.10 или новее (проверено на 3.15) и библиотека Pillow:

```bash
pip install pillow
python pixel_ruler.pyw
```

Если `pip` не находится, используй `python -m pip install pillow`
(на Windows удобно через лаунчер: `py -m pip install pillow` и `py pixel_ruler.pyw`).

## Сборка standalone .exe (Windows)
Чтобы получить программу, запускающуюся без установленного Python:

```bash
pip install pyinstaller
py -m PyInstaller --onefile --windowed --noconfirm --name PixelRuler --hidden-import=PIL._tkinter_finder --icon=icon.ico pixel_ruler.pyw
```

Готовый файл появится в `dist/PixelRuler.exe`.

## Своя иконка
Иконка приложения (`icon.ico`) генерируется скриптом из любой картинки рядом с ним:

```bash
py make_icon.py
```

Скрипт берёт первый найденный `.png`/`.jpg` в папке, режет по центру в квадрат и
складывает все размеры (16…256) в один `.ico`. Положи свою картинку в папку проекта
под именем вроде `icon_source.png` — и после `py make_icon.py` пересобери exe.

## Скачать готовую программу
Свежая сборка — в разделе **Releases** справа → `PixelRuler.exe`.
Первый запуск Windows может показать предупреждение SmartScreen («неизвестный
издатель») — это нормально для неподписанных сборок: «Подробнее» → «Выполнить
всё равно». Приложение работает офлайн; выбранный язык хранится локально в
профиле пользователя (`%APPDATA%\PixelRuler\config.json` на Windows) и никуда
не передаётся.
