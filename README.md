# Пиксельная линейка (Pixel Ruler)

Небольшая утилита на Python (Tkinter + Pillow) для измерения расстояний в пикселях
прямо на фотографии: ставишь точки, программа соединяет их в ломаную и считает
длину каждого отрезка и общую сумму. Есть приближение/перемещение фото, чтобы
точно попадать в пиксели, опция «замкнуть контур» для периметра и переключатель
языка интерфейса.

## Возможности
- Открытие фото (PNG / JPG / BMP / GIF / TIFF / WebP).
- Постановка точек левой кнопкой, удаление последней — правой кнопкой.
- Авто-соединение точек в последовательность 1→2→3→… и вывод длины каждого отрезка.
- Приближение колесом мыши (зум к курсору) и перемещение перетаскиванием.
- Опция «Замкнуть контур» — соединяет последнюю точку с первой.
- Панель замеров справа: координаты точек, длины, итог в пикселях.
- **Двуязычный интерфейс (RU / EN)** с переключателем в тулбаре; выбранный язык
  запоминается и подхватывается при следующем запуске, а при первом — определяется
  автоматически по языку системы.

## Управление
| Действие | Как |
|---|---|
| Поставить точку | Левый клик |
| Двигать фото | Зажать ЛКМ и тянуть |
| Удалить последнюю точку | Правый клик |
| Приблизить / отдалить | Колесо мыши |
| Открыть другое фото | Кнопка «Открыть изображение» |
| Сменить язык | Выпадашка «Язык» в тулбаре |

## Установка и запуск из исходников
Нужен Python 3.8 или новее и библиотека Pillow:

```bash
pip install pillow
python pixel_ruler.pyw
```

Если команда `pip` не найдена, используй `python -m pip install pillow`
(или `py -m pip install pillow` на Windows).

## Сборка standalone .exe (Windows)
Чтобы получить программу, которая запускается без установленного Python:

```bash
pip install pyinstaller
py -m PyInstaller --onefile --windowed --name PixelRuler --hidden-import=PIL._tkinter_finder --icon=icon.ico pixel_ruler.pyw
```

Готовый файл появится в `dist/PixelRuler.exe`.

## Скачать готовую программу
Свежая сборка лежит в разделе **Releases** справа → `PixelRuler.exe`.
Первый запуск Windows может показать предупреждение SmartScreen («неизвестный
издатель») — это нормально для неподписанных сборок: нажмите «Подробнее» →
«Выполнить всё равно». Программа работает полностью локально и никуда не
отправляет ваши данные и изображения.
