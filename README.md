# Пиксельная линейка (Pixel Ruler)

Небольшая утилита на Python (Tkinter + Pillow) для измерения расстояний в пикселях
прямо на фотографии: ставишь точки, программа соединяет их в ломаную и считает
длину каждого отрезка и общую сумму. Есть приближение/перемещение фото, чтобы
точно попадать в пиксели, и опция «замкнуть контур» для периметра.

## Возможности
- Открытие фото (PNG / JPG / BMP / GIF / TIFF / WebP).
- Постановка точек левой кнопкой, удаление последней — правой кнопкой.
- Авто-соединение точек в последовательность 1→2→3→… и вывод длины каждого отрезка.
- Приближение колесом мыши (зум к курсору) и перемещение перетаскиванием.
- Опция «Замкнуть контур» — соединяет последнюю точку с первой.
- Панель замеров справа: координаты точек, длины, итог в пикселях.

## Управление
| Действие | Как |
|---|---|
| Поставить точку | Левый клик |
| Двигать фото | Зажать ЛКМ и тянуть |
| Удалить последнюю точку | Правый клик |
| Приблизить / отдалить | Колесо мыши |
| Открыть другое фото | Кнопка «Открыть изображение» |
